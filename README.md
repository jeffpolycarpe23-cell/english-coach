# 🎓 English Coach

Interactive English learning platform with 25 essential structures and 200 practical phrases.

## ✨ Features

- **25 Grammar Structures** - Most used in the world
- **200 Practice Phrases** - 8 examples per structure
- **Speech Recognition** - Real-time pronunciation correction
- **Interactive Chatbot** - Practice oral and written English
- **Modern Design** - Beautiful gradient UI
- **Multilingual Support** - English, French, Kreyòl
- **Fully Responsive** - Works on all devices
